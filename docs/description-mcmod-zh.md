# 模拟殖民地：阡陌纵横 / MineColonies: Crossroads

MineColonies 的道路扩展。用道路绘制器规划轴向直路，生成真正的 Structurize 蓝图，交给**原生**建造流程施工；建成后由原版装饰控制器长期管理，支持逐格编辑、修复、升级与拆除。

MineColonies 擅长造房子，但道路只能靠玩家自己一块块铺。这个模组补上「路」这一层，并且**不替换**任何已有机制：建造工具、工单、权限、控制器全部来自上游。

## 主要功能

- **规划与建造**：手持道路绘制器左键选 A、Shift 左键选 B，两点决定端点与走向，生成严格宽度的 Structurize 蓝图；Complete / Pretty 走原生即时队列，Survival 变成殖民地建筑工的一张真工单。
- **两套系列与升级**：街道（4 格宽，1–3 级）与主路（5 格宽，1–4 级），共 21 份单元；控制器面板可换风格、系列与等级，已建成的路派工单由建筑工重铺。
- **路口与分层穿越**：同层路口自动并成一段平路；上跨 / 下穿逐格保证 3 格路面差与 2 格通行净空；邻路无权限时可发请求，未获批准则严格避让。
- **地形挖填**：绘制器切「挖掘 / 填充选区」，框选后生成蓝图并打开原生建造工具，由建筑工按 CLEAR / PLACE 清空或铺满。
- **管理与权限**：道路清单按殖民地多选管理（释放 / 拆除），工单清单可批量取消；权限完全复用 MineColonies 的 `MANAGE_HUTS`，不做放宽。

## 三件工具

| 物品 | 用途 |
|---|---|
| 道路绘制器 | 选点规划、逐行编辑、预览幽灵、打开建造工具、切换地形选区 |
| 道路清单 | 查看并多选管理殖民地内的道路 |
| 工单清单 | 查看并批量取消殖民地工单 |

三件物品都在本模组的创造模式分页里，配方可在游戏内配方书查看。
